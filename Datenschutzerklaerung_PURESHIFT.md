## 2. Allgemeines zur Datenverarbeitung
PURESHIFT ist eine Schichtplaner-App. Sämtliche von Ihnen eingegebenen Daten (Schichten, Kalender, Schichttypen, PDF-Vorlagen, Einstellungen) werden **ausschließlich lokal auf Ihrem Endgerät** gespeichert. Es findet **keine Übertragung an einen Server des Anbieters** und **keine Cloud-Synchronisation** statt.

Die App funktioniert vollständig offline. Eine Registrierung oder ein Nutzerkonto ist nicht erforderlich.

## 3. Welche Daten werden lokal verarbeitet?
Folgende Daten werden ausschließlich auf Ihrem Gerät gespeichert:
- Schichten und Schichteinträge (Datum, Uhrzeiten, Notizen)
- Schichttypen (Bezeichnung, Farbe, Stundenangaben, Zuschläge)
- Kalender- und Gruppenbezeichnungen
- PDF-Export-Vorlagen und -Einstellungen
- App-Einstellungen (Sprache, Theme, Anzeigeoptionen)

Diese Daten verlassen Ihr Gerät nur dann, wenn **Sie** dies aktiv veranlassen (siehe Abschnitt 4).

## 4. Vom Nutzer ausgelöste Datenexporte
### 4.1 Datensicherung (Backup / Restore)
Sie können über die Funktion „Datensicherung" eine JSON-Datei mit Ihren App-Daten exportieren bzw. wieder importieren. Die Datei wird an dem von Ihnen gewählten Speicherort (Gerätespeicher, Cloud-Dienst, Messenger usw.) abgelegt. Für den weiteren Umgang mit dieser Datei sind Sie selbst verantwortlich.

### 4.2 PDF-Export
Beim Erstellen eines PDF-Dokuments aus Ihren Schichtdaten wird die Datei lokal erzeugt und kann anschließend von Ihnen geteilt, gedruckt oder gespeichert werden. Auch hier erfolgt keine Übermittlung an den Anbieter.

## 5. Berechtigungen
Die App fordert ausschließlich Berechtigungen an, die für ihre Funktion erforderlich sind:
- **Speicherzugriff / Dateisystem:** zum Schreiben und Lesen von Backup- und PDF-Dateien.
- **Benachrichtigungen** (sofern aktiviert): für Erinnerungen an Schichten – die Verarbeitung erfolgt lokal auf dem Gerät.

Sie können erteilte Berechtigungen jederzeit in den Systemeinstellungen Ihres Geräts widerrufen.
