## 2. Allgemeines zur Datenverarbeitung

PURESHIFT ist eine Schichtplaner-App mit Mitarbeiterverwaltung. Sämtliche von Ihnen eingegebenen Daten werden **ausschließlich lokal auf Ihrem Endgerät** gespeichert. Der Anbieter betreibt **keinen Server**, empfängt **keine Daten** und bietet **keine Cloud-Synchronisation** an.

Die App funktioniert vollständig offline. Eine Registrierung oder ein Nutzerkonto ist nicht erforderlich.

Daten verlassen Ihr Gerät nur, wenn Sie dies selbst veranlassen (Abschnitt 5) oder wenn das Betriebssystem Ihres Geräts eine Datensicherung durchführt (Abschnitt 7).

## 3. Welche Daten werden lokal verarbeitet?

Folgende Daten werden auf Ihrem Gerät gespeichert:

- Schichten und Schichteinträge (Datum, Uhrzeiten, Notizen), Schichttausch-Einträge
- Schichttypen (Bezeichnung, Farbe, Stundenangaben, Zuschläge) und Schichtgruppen
- Kalender- und Gruppenbezeichnungen
- Einstellungen zu Währung, Gehalts- bzw. Steuerberechnung, Bundesland, Sprache, Darstellung und Widgets
- Startzeitpunkt einer laufenden Zeiterfassung (Timer)
- PDF-Export-Vorlagen und -Einstellungen
- **Mitarbeiterdaten**, sofern Sie die Mitarbeiterverwaltung nutzen und befüllen (alle Felder sind freiwillig):
  - Name, Geburtsdatum
  - Kontaktdaten (E-Mail privat/dienstlich, Telefon, Mobilnummer, Anschrift)
  - Beschäftigungsdaten (Eintritt/Austritt, Beschäftigungsart, Abteilung, Position, Standort)
  - Vergütungsdaten (Gehalt, Bankverbindung, Steuerklasse)
  - Sozialversicherungsdaten (Sozialversicherungsnummer, Steuer-ID, Kranken- und Rentenversicherung)
  - Urlaubsdaten sowie Qualifikationen, Zertifikate und Schlüsselübergabe

Für die Android-Widgets wird außerdem ein Schichtsnapshot lokal auf dem Gerät abgelegt.

## 5. Vom Nutzer ausgelöste Datenübertragungen

### 5.1 Datensicherung (Backup / Restore)

Über die Funktion „Datensicherung" können Sie eine JSON-Datei mit Ihren App-Daten (einschließlich Mitarbeiterdaten) exportieren und wieder importieren. Die Datei ist **nicht verschlüsselt** und wird an dem von Ihnen gewählten Speicherort (Gerätespeicher, Cloud-Dienst, Messenger usw.) abgelegt. Für den sicheren Umgang mit dieser Datei sind Sie selbst verantwortlich. Der Anbieter erhält keine Kopie.

### 5.2 PDF-Export

Beim Erstellen eines PDF-Dokuments aus Ihren Schichtdaten wird die Datei lokal erzeugt. Sie können sie anschließend teilen, drucken oder speichern. Es erfolgt keine Übermittlung an den Anbieter.

### 5.3 Kalender teilen

Die Funktion „Kalender teilen" erzeugt lokal ein Bild Ihres Schichtkalenders. Dieses können Sie über die Teilen-Funktion Ihres Geräts an Dritte senden. Mit wem Sie es teilen, entscheiden Sie allein.

### 5.4 WLAN-Freigabe (Synchronisation zwischen Geräten)

Die App bietet optional eine „WLAN-Freigabe". Wenn Sie diese aktivieren, startet die App auf Ihrem Gerät einen lokalen Server, der im selben lokalen Netzwerk (WLAN) erreichbar ist. Ein anderes Gerät (z. B. Ihr zweites Smartphone oder ein Computer) kann sich mit einer von der App angezeigten PIN koppeln und anschließend Ihre App-Daten abrufen oder übermitteln. Dabei werden alle App-Daten, auch Mitarbeiterdaten, übertragen.

Bitte beachten Sie:

- Die Freigabe ist **standardmäßig ausgeschaltet** und wird nur durch Sie aktiviert.
- Die Übertragung erfolgt **innerhalb Ihres lokalen Netzwerks** und **ohne Verschlüsselung (HTTP)**. Nutzen Sie sie nur in vertrauenswürdigen Netzwerken (nicht in öffentlichen WLANs).
- Es werden keine Daten an den Anbieter oder an Server im Internet gesendet.
- Gekoppelte Geräte können Daten lesen und, je nach Einstellung, ohne weitere Bestätigung Daten zusammenführen oder überschreiben. Sie können die PIN jederzeit neu erzeugen; dadurch verlieren alle gekoppelten Geräte den Zugriff.
- Schalten Sie die Freigabe nach der Nutzung wieder aus.
